# 📘 English Master AI — Extension WordPress Complète

> **L'application d'anglais la plus complète du débutant à l'avancé (A1 à C2)**  
> Conçue pour WordPress avec intelligence artificielle, analyse vocale en temps réel, répétition espacée (SRS), tuteur conversationnel et délivrance de certificats officiels.

---

## 🌟 Fonctionnalités Incluses (Conformes à la maquette)

### 1. 🗺️ Parcours Complet CECRL (A1 à C2)
* **A1 - Débutant** : Salutations, verbe être, routine quotidienne, premiers nombres.
* **A2 - Élémentaire** : Daily Life, At the Restaurant, Traveling, At the Hotel, Shopping, Communication.
* **B1 - Intermédiaire** : Present Perfect, aéroport, emails professionnels, phrasal verbs.
* **B2 - Intermédiaire Supérieur** : Conditionnels complexes, négociation d'affaires, débat.
* **C1 - Avancé** : Inversion grammaticale, nuances rhétoriques, style soutenu.
* **C2 - Maîtrise** : Maîtrise bilingue et culturelle de niveau natif.

### 2. ⚡ Tous les Modules Essentiels
* **🎙️ Prononciation & Score Vocal IA** : Reconnaissance vocale (Web Speech API) avec calcul du score de précision (ex: 87%), synthèse vocale et conseils phonétiques ciblés.
* **📖 Grammaire Interactive** : Règles avec formules claires (ex: `have/has + past participle`), exemples bilingues et quiz avec explications instantanées.
* **📚 Vocabulaire avec Répétition Espacée (SRS)** : Algorithme SuperMemo-2 (Nouveau, À apprendre, En cours, À revoir, Maîtrisé).
* **🎧 Listening (Compréhension Orale)** : Extraits audio naturels et questions à choix multiples avec correction immédiate.
* **🤖 Conversation IA (Tuteur en Direct)** : Dialogues interactifs par scénarios (Hôtel, Restaurant, Entretien d'embauche, Conversation libre) avec analyse des erreurs et suggestions.
* **✏️ Atelier d'Écriture** : Analyse de texte par l'IA avec retour sur la grammaire, le niveau de vocabulaire et attribution de points XP.
* **📑 Phrasal Verbs & 💡 Idioms** : Fiches illustrées avec prononciation audio, traductions et contextes d'utilisation.
* **📖 Dictionnaire Audio** : Recherche instantanée de termes avec transcriptions API phonétiques et audio TTS.

### 3. 🎮 Gamification, Suivi & Certificats
* **🔥 Série quotidienne (Streaks)** et jauge d'objectifs (ex: 20/30 min).
* **⚡ Points d'expérience (XP) et Badges** débloqués au fil des leçons.
* **📊 Test d'Évaluation Initiale** pour placer automatiquement l'apprenant au bon niveau.
* **📜 Certificat Officiel** imprimable et exportable en PDF (B1 Intermediate, etc.).

## 🚀 Guide d'Installation sous WordPress

### Option A : Copie directe dans le dossier Plugins
1. Copiez l'ensemble du dossier `english master ai` dans votre répertoire WordPress :  
   `wp-content/plugins/english-master-ai/`
2. Connectez-vous à votre panneau d'administration WordPress.
3. Rendez-vous dans **Extensions > Extensions installées**.
4. Cliquez sur **Activer** sous **English Master AI**.

### Option B : Création d'une archive ZIP
1. Compressez le dossier en `english-master-ai.zip`.
2. Dans WordPress, allez dans **Extensions > Ajouter une extension > Téléverser une extension**.
3. Choisissez le fichier zip et activez-le.

## 📌 Utilisation sur votre Site WordPress

### 1. Via Shortcode
Pour intégrer l'application sur n'importe quelle page ou article :
1. Créez une nouvelle page WordPress (ex : *Apprendre l'anglais*).
2. Ajoutez le bloc **Court-code** (Shortcode) et collez :
   ```text
   [english_master_ai]
   ```
3. Publiez la page ! L'application sera instantanément opérationnelle.

### 2. Via l'URL Plein Écran Dédiée
Le plugin active automatiquement une route immersive sans barre de menu parasite :
```text
https://votresite.com/learn-english/
```

## ⚙️ Configuration & Moteur IA

Dans le menu WordPress **English Master AI > Réglages & IA** :
* **Fournisseur IA** :
  * *Moteur IA Hybride Intégré (Recommandé)* : Fonctionne sans aucune configuration ni frais d'API.
  * *OpenAI API (GPT-4o / GPT-4o-mini)* : Entrez simplement votre clé `sk-...`.
  * *Google Gemini API* : Entrez votre clé `AIzaSy...`.
* **Personnalisation des Certificats** : Définissez le nom de votre académie/école et le signataire officiel.
